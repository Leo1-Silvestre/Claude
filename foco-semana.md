# Foco da Semana

Edite este arquivo toda semana com as 2-3 aulas de foco. Para cada aula,
voce pode indicar:

- `dificuldades:` pontos que o gerador deve priorizar cobrir (lista
  separada por virgula)
- `obs:` (ou `comentarios:`/`instrucoes:`) instrucoes livres que o
  gerador deve seguir a risca, tipo "evitar questoes de conta, focar nas
  teoricas"

Um item indentado sob "- Aula NN" vale so para aquela aula. Um item sem
indentacao (logo apos "## materia") vale para a materia toda.
